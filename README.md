# RetailPulse BI – Business Sales Performance Analytics

## Project Overview

RetailPulse BI is a business sales performance analytics project developed as part of the Future Interns Data Science & Analytics Internship (Task 1).

The project analyzes retail sales data to identify revenue trends, profitable product categories, regional performance, top-selling products, and loss-making sub-categories.

## Objectives

- Analyze overall business sales and profitability.
- Identify top-performing products and categories.
- Evaluate regional sales performance.
- Analyze monthly revenue trends.
- Identify loss-making product sub-categories.
- Develop actionable business recommendations.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI
- Jupyter Notebook / VS Code

## Dataset

**Dataset:** Sample Superstore

- Total records: 9,994
- Total columns after cleaning: 25
- Missing values after cleaning: 0
- Duplicate records after cleaning: 0
- Period: 2014–2017

## Project Workflow

1. Dataset collection
2. Data cleaning using Python and Pandas
3. Exploratory Data Analysis (EDA)
4. Sales and profitability analysis
5. Visualization using Matplotlib
6. Interactive dashboard development using Power BI
7. Business insights and recommendations

## Key Findings

- Technology generated the highest category revenue.
- Office Supplies generated the highest category profit.
- West was the leading region by revenue and profit.
- Tables, Bookcases and Supplies recorded negative profits.
- Canon imageCLASS 2200 Advanced Copier was the highest-revenue product.

## Power BI Dashboard

The interactive Power BI dashboard includes:

- Sales Overview
- Product & Profitability Analysis
- KPI cards
- Monthly revenue trend
- Category and regional sales analysis
- Top 10 products by revenue
- Sub-category profitability
- Year, Region and Category slicers

## Business Recommendations

- Review pricing and discount strategies for loss-making products.
- Focus on high-performing technology products.
- Improve profitability in the Central region.
- Monitor product-level profit margins.
- Strengthen marketing strategies for profitable categories.
